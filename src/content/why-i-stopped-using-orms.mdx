When I first started building web applications, ORMs felt like magic. I could write `User.find()` and everything just worked. But as my applications scaled, that magic turned into a performance bottleneck.

It always starts the same way. You load a list of posts, and then you want to load the author for each post. Suddenly, your database is crying because you just executed 100 separate queries.

Writing raw SQL (or using a lightweight query builder) forces you to understand the data structures you are actually executing. It brings you closer to the metal.
